# Security Policy

Do not place API keys, access tokens, `.env` contents, real-person photographs, user spreadsheets, business data, generated character media, or raw provider responses in a public issue or pull request.

If you discover a vulnerability, use GitHub's private vulnerability reporting feature if it is enabled for the repository. Otherwise, contact the repository maintainer through an available private channel. Do not publish exploit details before the maintainer has had a reasonable opportunity to investigate.

When reporting a vulnerability, include affected versions, reproduction steps using synthetic data, expected impact, and any suggested mitigation. Remove secrets and personal data from logs before sharing them.
