# Development Notes

TaskPet evolved from a small React desktop-pet interaction demo into a local full-stack prototype.

- The frontend established page state, pet interaction, chat, drag boundaries, and browser-session recovery.
- Character creation added browser-side person detection, backend image generation, transparent normalization, a persistent local Character Library, state-specific assets, and walking motion.
- Workspace file handling added `.xlsx` upload, local runtime storage, repeatable file-to-pet interaction, and task execution states.
- Data work added deterministic Excel analysis, optional structured AI insights, a real-data dashboard, and local recent-task/history restoration.
- Public-release preparation removes development prompts, private assets, runtime data, credentials, and environment-specific configuration while keeping the reusable architecture.

The current project remains a local single-user prototype. Production authentication, multi-user storage, deployment automation, monitoring, and cloud synchronization are outside the present scope.
